OLYMPUS AI — INSTALLATION

1. Upload/copy these six files into the same folder as MainUI.html:
   ai-config.js
   ai-catalog.js
   ai-engine.js
   ai-navigation.js
   ai-ui.js
   olympus-ai.css

2. In MainUI.html, add this stylesheet link inside <head>, after existing stylesheets:
   <link rel="stylesheet" href="./olympus-ai.css">

3. Add this module script immediately before the closing </body> tag:
   <script type="module" src="./ai-ui.js"></script>

The AI catalogue discovers real .nav-btn[data-tab] buttons and their matching
<section>-section elements at runtime. Navigation uses the existing window.switchTab().
No Supabase calls, database writes, or chess/game logic changes are made.

This first version is a lightweight local navigation assistant, not a generative
ChatGPT/LLM connection. It requires no API key.
